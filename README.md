# 树与叶 · 成家小屋

丁树凯与叶小妹的版本3互动婚礼请柬。婚期：2026年11月22日。

正式候选入口：https://bryantding.github.io/wedding-invitation/

本仓库保存可直接发布的静态网页。六幕包括拆信、童年翻卡、推门成家、18张婚纱照、喜糖与正式邀请，保留音乐、晚灯、彩蛋和纪念票交互。所有主要图片和音频都位于本站assets目录。

GitHub Pages从main分支根目录发布；.nojekyll保证按普通静态文件提供服务。使用相对资源路径，可在项目子路径下运行。

微信分享准备页：share.html。页面中的卡片为效果示意，固定微信封面需要接通分享服务并在真实微信中验证。GitHub Pages上线本身不代表国内所有网络和微信卡片已经验收。

本仓库是用户授权的公开仓库，保存了请柬照片、代码及婚宴地址。原版本1、2和适配前版本3另行保留，不在本次部署中覆盖。

当前配乐仍沿用版本3的临时录像来源音轨。没有后台回执服务，不上传纪念票昵称。
